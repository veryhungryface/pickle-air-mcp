# 검증 범위

## 기준 환경

- Apple Silicon arm64, macOS 26 / Darwin 25.3.0
- 실제 실행 Python 3.14.8. 최소 요구 버전은 3.9이나 3.9에서의 실기 실행은 미검증
- BlueStacks Air 5.21.790.7505
- Android 13의 Pickle 앱
- 기존 로컬 ADB, Swift, macOS 손쉬운 사용 권한
- BlueStacks 전면 유지, 실행 중 수동 조작 없음

이 기록은 한 환경에서 확인한 개념 검증 결과입니다. 다른 컴퓨터·앱 버전·화면 배율·계정·언어 조합의 동작까지 보장하지 않습니다. 신규 권한 부여나 인증 키 생성은 수행하지 않았습니다.

## 확인된 결과

| 항목 | 결과와 범위 |
| --- | --- |
| 명령 도움말 | 루트와 `doctor`, `read`, `ask`, `download`의 `--help` 실행 확인 |
| 한글 질문과 응답 | 실제 앱에서 한글 질문 전송과 짧은 한글 응답 확인 |
| 유니코드 입력 경로 | Swift/AppKit, 기존 권한, Mac 클립보드 보존, BlueStacks 입력 경로 확인 |
| PNG·TXT 첨부 | 비민감 테스트 파일을 기본 Files 선택기로 선택해 실제 전송 확인 |
| 한글 응답 파일 다운로드 | 실제 382바이트 파일을 Mac으로 저장하고 UTF-8 내용과 SHA-256 일치 확인 |
| 최종 통합 실행 | 최신 코드로 ASCII 질문 + PNG·TXT 첨부 + 전송 + 응답 생성 + 166바이트 파일 자동 다운로드 통과. SHA-256 일치 확인 |
| 단위 테스트 | 합성·모의 입력 기반 17개 통과 |

첨부는 복사 해시, 선택기 파일명과 첨부 개수를 확인했습니다. 최종 첨부 표시에서 파일명을 얻지 못하므로 최종 파일 정체성을 검증했다고 주장하지 않습니다. 같은 개수로 바뀌는 동시 조작과 모든 업로드 상태는 감지하지 못합니다.

Mac 클립보드는 실행 중 다른 변경이 없을 때 기존 형식으로 복원합니다. Android 클립보드는 제출 텍스트로 바뀌며 복원하지 않습니다.

## 단위 테스트

`tests/test_cli.py`에는 앱을 조작하지 않는 합성·모의 입력 기반 테스트가 들어 있습니다. ADB 프레임·연결 오류, 포트 범위, 중복 요청, 요청 ID·파일명 제한, 기존 파일 보존, 기록의 본문 미포함, 잘못된 대화·기존 초안·모호한 UI 거부 등을 다룹니다.

```sh
python3 -m unittest discover -s tests -v
```

최종 코드에서 17개가 통과했습니다. 단위 테스트와 실제 앱 통합 검증은 별도이며, 위 표에 확인 범위를 나누어 적었습니다.

## 아직 보장하지 않는 범위

- JPG/JPEG/PDF/CSV 실제 첨부, 최대 개수·용량의 실기 테스트
- 영어 UI 전체 흐름, 다른 UI 배율·해상도, 앱 업데이트
- Windows, Intel Mac, 다른 Android 에뮬레이터
- 로그인 만료·권한 팝업·네트워크 단절·강제 종료의 모든 조합
- 동시 수동 조작·외부 자동화에 대한 완전한 차단
- 장문·느린 스트리밍 답변의 정확한 완료 판단
- 모든 파일 저장 지연에서의 완전성, 무인 운영 안정성

## 새 환경에서 확인할 순서

1. `doctor` 결과의 연결·Swift·권한 정보를 확인합니다.
2. 대상 대화를 열고 `read`로 현재 보이는 내용만 확인합니다.
3. 개인 정보 없는 짧은 ASCII 질문과 한글 질문을 각각 한 번 보냅니다.
4. 합성 PNG와 TXT로 첨부를 확인합니다. 전송 중에는 앱을 건드리지 않습니다.
5. 합성 응답 파일을 내려받고 내용·크기를 직접 확인합니다.
6. 오류나 시간 초과가 나면 기존 전송과 남은 초안·첨부부터 확인합니다. 자동 재전송하지 않습니다.

기록에는 실제 에이전트명·대화·개인 경로·파일 원본을 넣지 않았습니다. 재현 보고나 공유 ZIP에도 이런 자료를 추가하지 마세요.
